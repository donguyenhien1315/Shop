CANTIN AI V2.1 - BẢN KHÔNG DÙNG REPLIT

CÁCH 1 - CHẠY TRÊN WINDOWS / MAC / LINUX
1. Cài Node.js 20 trở lên.
2. Giải nén thư mục dự án.
3. Mở Terminal/CMD trong thư mục.
4. Chạy: npm install
5. Chạy: npm start
6. Mở trình duyệt: http://localhost:3000

CÁCH 2 - DOCKER
1. Cài Docker Desktop.
2. Chạy: docker compose up -d --build
3. Mở: http://localhost:3000

DỮ LIỆU
- Không có DATABASE_URL: lưu tại data/store.json.
- Có DATABASE_URL: lưu PostgreSQL, phù hợp khi đưa lên Internet.

BẢO MẬT
- Tạo file .env từ .env.example.
- Đặt APP_PIN và SESSION_SECRET trước khi public web.
